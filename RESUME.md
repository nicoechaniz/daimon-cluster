# Daimon Cluster

Start with [the project overview](README.md) and [the design index](docs/DESIGN.md).
Use the maintained [routine maintenance procedure](docs/runbooks/tribu-sdk-successor.md#supported-routine-maintenance-command)
for receiver-compatible updates and the [onboarding contract](docs/design/onboarding-jobs.md)

Deployment selections, placements, maintenance evidence and approvals belong in
the authorized operations register. Resolve current bindings there before
operating on a receiver. Public documentation describes reusable contracts and
uses synthetic examples.
