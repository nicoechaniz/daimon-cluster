# Daimon Matrix interface direction

The human-selected direction is Star Trek: advanced technology serving an
expanding community. Express that through a distinct Daimon Matrix interface,
with clear operations, calm confidence and visible continuity between beings,
humans and their bodies. This visual language changes no Matrix ontology or
authority.

## Visual vocabulary

Use deep space as the canvas, warm ivory for primary text and amber for the
current action. Cyan describes relation and navigation; mauve provides a small
secondary accent. Muted blue-gray surfaces and borders establish depth without
competing with the content. Green indicates an observed successful state.

| Token | Value | Role |
| --- | --- | --- |
| Space | `#090e17` | Main canvas |
| Panel | `#111925` | Grouped operations |
| Ink | `#f5f0e6` | Primary text |
| Muted | `#abb7c9` | Supporting text |
| Amber | `#f4c283` | Current step and primary action |
| Cyan | `#87d7ee` | Links, focus and relation |
| Mauve | `#dcb3c3` | Secondary accent |
| Green | `#a8dac6` | Verified success |

Legibility is a first requirement for **every visible text**, including labels,
help, status, captions, technical detail and navigation. Do not create a clean
composition by shrinking secondary text. This intake uses 16px body/input text
and at least 14px supporting text at normal browser zoom. Small screens retain
those sizes; rearrange or wrap content instead. Check contrast, line height and
real rendering, not only CSS declarations. Browser text zoom must remain usable.

Space Grotesk supplies a human, technical voice. Self-host the Latin font with
its SIL Open Font License and provenance; retain a system fallback. Orbital
paths and an interference wave form the own visual mark. Segmented control
lines recall LCARS without reproducing franchise logos or filling the screen
with decorative controls.

## Communication and behavior

Lead with the person's next meaningful choice. The intake journey is Origin,
Continuity and Connections. Ordinary users select identity and memory through
labeled controls; archive paths and raw selection JSON are progressive detail.
Technical precision remains available without becoming the whole interface.

Distinguish an uploaded package, preserved working context, supplied connection
data and an accepted running body. Show actual counts and useful pending work.
Keep identity prose, private history and credentials out of public progress.
An idle indicator means the intake is available, never that a daimon is active.

Use the same accent, rhythm and type hierarchy across empty, working, error and
prepared states. Keep text selectable, controls labeled, keyboard focus visible
and reduced motion supported. On small screens, stack the journey and progress
without horizontal scrolling. Keep primary touch actions at least 44 CSS pixels.

Inspect the rendered desktop and narrow layout before delivery. Exercise the
real private-access, continuity and connection paths with synthetic data. A
screenshot of a beautiful empty form alone does not establish a usable interface.

Humans and daimons enter through the same URL. The authored Markdown/JSON views
expose the actual API contract, access requirements and completion boundary.
Visual presentation and machine rendering must describe the same service.
